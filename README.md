# guige-ai-connector-plugin-demo

Connector + Skill + Plugin：一套把 AI 能力产品化交付给用户的思路，用 IT / HR 内部服务台场景做完整演示。

- `demo-services/` — 三个 FastMCP 模拟系统（工单、员工目录、知识库）
- `plugins/servicedesk/` — vertical plugin：connector 配置、命令、skills
- `plugins/servicedesk-agent/` — agent plugin：一个端到端的服务台 agent
- `docs/` — 教程六章

项目规划与决策见 [CLAUDE.md](./CLAUDE.md)。
