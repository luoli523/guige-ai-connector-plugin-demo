# 入职准备清单模板

按人分节，pending 多的排前面。

```
# 入职准备清单（截至 YYYY-MM-DD）

共 N 人在入职中，M 项待办。

## 姓名（岗位，团队）

- 入职日期：YYYY-MM-DD（第 X 天）
- 上级：姓名
- buddy：姓名 / **未指定**
- 设备：型号（资产号） / **未分配**

| 清单项 | 状态 | 责任人 | 备注 |
|---|---|---|---|
| 签署入职文件 | 完成 | | |
| 领取笔记本 | **待办** | IT | 无设备记录 |
| 激活公司账号并绑定 MFA | **待办** | 本人 + IT | 入职第 X 天仍未绑定，参考 KB-109 |
| ... | | | |

相关工单：T-xxxx 标题（状态） / 无

**建议动作**：一句到三句，谁今天该做什么。
```

结尾加一节：

```
## 建议建单

| # | 标题 | 提单人 | 类别/优先级 |
|---|---|---|---|
| 1 | 新员工 姓名 权限开通：系统 | 上级 E-xxxx | it / medium |

确认后逐张创建。
```
